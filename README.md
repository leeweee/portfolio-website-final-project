# Dahye Daisy Lee Portfolio

This is a five-page photography portfolio website built for my final project.

## Pages
- Home
- About
- Gallery
- Project
- Contact

## Features
- HTML, CSS, and JavaScript
- Responsive design for mobile, tablet, and desktop
- Google Font
- Contact form
- Embedded iframe
- Dark mode toggle
- Gallery grid
- Card layout

## Reflection
I built a personal photography portfolio website that introduces my work, background, gallery images, project concept, and contact information. I wanted the site to feel simple, warm, and easy to navigate.

I am most proud of the dark mode toggle because it uses JavaScript to change the visual style of the site. I also like the gallery page because it presents images in a clean grid.

The hardest part was making the layout responsive across different screen sizes. I solved this by using media queries for mobile, tablet, and desktop layouts.
